Sistem ini terhubung langsung ke API Google Apps Script yang Anda berikan untuk operasional CRUD (Create, Read, Update, Delete) secara realtime. State Management: Halaman dan menu terakhir yang dibuka akan tetap bertahan meskipun di-refresh. Integrasi Spreadsheet: Menggunakan metode fetch (GET/POST) ke URL API Google Script untuk sinkronisasi data books, sales, royalty, expenses, projects, dll. Fitur PDF Premium: Generator laporan Penjualan dan Royalti dengan desain profesional (Header, Footer, Tabel, Tanda Tangan).
